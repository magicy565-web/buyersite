# Buyersite three-stage integration acceptance

This release combines the work from the stacked builder, visual-director and media-review branches with a public magazine, buyer enquiry storage and editorial feedback. The reviewed edition is **Material Notes**, an independent source-based Burel Factory material review. Synthetic enterprise previews retain their separate private boundaries.

**Live site:** https://buyersite.magicy565.chatgpt.site/ — public access verified in the browser. The deployed homepage returned 200, a matching canonical URL and `index, follow, max-image-preview:large`; robots and sitemap returned 200. The inbox API still returned 401 without owner authentication.

## Delivered behavior

1. **Editorial production:** four reusable editorial blocks; Atelier, Industrial and Editorial profiles; strict authorized-photo import and grant checks; consent-gated image generation; artifact-bound screenshot review. The live edition uses three original AI concept images with visible labels, source bindings and SHA-256 provenance.
2. **Buyer conversion:** React / assistant-ui sourcing dialog, exact source-fact lookup, a consented enquiry form, durable receipts, duplicate prevention, owner review and a local unsent-brief download. The optional live AI adapter is installed but unconnected.
3. **Publication and feedback:** Pagefind search; canonical links, structured data, robots and sitemap controls; an Astro static magazine served by a Cloudflare Worker; D1 enquiry and aggregate-event tables; authenticated aggregate feedback for the existing editorial workflow.

## Connections that remain external

- **Live OpenMausBot AI:** no deployed service has been verified against the adapter's sessions/chat REST contract. The documented magazine MCP endpoint is not an interchangeable REST endpoint. The UI shows a working cited source guide while this connection is absent.
- **Google Search Console and Umami:** unconnected. The deployed first-party event collection and owner feedback are independent of those accounts. Sitemap availability does not mean Google has indexed the site.
- **Real licensed supplier photography:** no commercial asset with a real grant was supplied. The authorized-photo path was exercised with synthetic grant fixtures, while this edition uses actual generated concepts.
- **Automated enterprise production:** existing Studio ingestion, production gateway credentials and paid image/vision API configuration were not proven by these synthetic checks. No OpenMausBot production service was modified.

The acceptance runs created no supplier communication, quote, order or sales claim. Test enquiries are archived and must not be treated as qualified buyer demand.
