## P1 · 把样板刊做成“有得翻”的一期

### 内容（需要资料）
- [ ] `[阻断]` 收集可引用的资料：Burel 其他公开页面、产品目录、技术规格表、FAQ。每条事实入 `src/data/evidence.json`，带 URL、原文引用、采集时间。
- [ ] `[可做→阻断]` 新增 3–5 篇不同类型稿件，每篇一个 `pageType` 和专属版式：
  - [ ] 主专题：一个真实采购问题（如“室内项目选羊毛面料先确认的五件事”）
  - [ ] 对比稿：2–3 种材料/工艺并排
  - [ ] 术语/口径页：解释 g/m、幅宽、色牢度等计量口径
  - [ ] 简讯栏：几条短消息，带来源与日期
- [ ] `[可做]` 每篇新稿件在 `buyer-briefs.json` 中写好 unconfirmed 与 questions，确保询盘能带上下文。

### 未改造的页面
- [ ] `[可做]` `/sources/` 来源页：按页面分组的账本式排版，过期/冲突/缺失状态可视化。
- [ ] `[可做]` 指南页的问题清单（`BuyingChecklist`）改成编号问题卡样式，和事实账本统一。
- [ ] `[可做]` `/search/` 搜索页与采购助手对话框：套用新版字体层级与纸张质感。
- [ ] `[可做]` `/colophon/`、`/privacy/`、404：套用版心、页眉页码。

### 版式细节
- [ ] `[可做]` 事实账本新增两种变体：`comparison`（两个产品左右并排对比）、`timeline`（样品 → 确认 → 报价流程）。同步加进 `layout-planner.mjs` 白名单、schema 和单元测试。
- [ ] `[可做]` 图片说明精简：图片下只留短标签（如“AI 概念图”），完整声明放在页尾“本刊如何制作”。`heroCaption` / `heroCredit` 记录不能删，浏览器测试里的说明可见性检查要同步调整。
- [ ] `[可做]` 字体层级：评估并自托管一款标题展示字体（通过 `astro.config.mjs` 的 fonts 配置，禁止 CDN），跑对比度检查。
- [ ] `[可做]` 清理旧代码：删除已被取代的 `EditionCover`、`SupplierFeature`、`SpecSummary`，以及 `theme.css` 中失效的 `.grid article` 规则。

## P2 · 杂志手感

- [ ] `[可做]` 跨页（spread）：≥ 80rem 时，专题与对比稿用“左图右文”对开页，翻页动画落在对开页上。
- [ ] `[可做]` 手机端滑动翻页：只在页尾区域响应横向滑动，避免和顶栏、表格的横向滚动冲突。需要触控测试与 `prefers-reduced-motion` 退化。
- [ ] `[可做]` 刊期：引入“本期/往期”概念（`edition` 字段、期号页、往期存档页）。注意：Halftone 原规则是“无期号”，这里要在 `docs/v2/EDITORIAL-DESIGN-SYSTEM.md` 记录推翻理由。
- [ ] `[可做]` 翻页检查（`scripts/check-page-turn.mjs`）加入 Playwright 套件，在三个视口都跑。
